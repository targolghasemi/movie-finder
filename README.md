 Movie Finder

Movie Finder is a React web application that allows users to discover movies, search for their favorite titles, and explore movie details using the TMDB API.

✨ Features

Movie Discovery: Browse movies fetched from the TMDB API.

Movie Search: Search for movies by title.

Search Suggestions: Get movie suggestions while typing, with debounced search to reduce unnecessary requests.

Movie Details: View detailed information about a selected movie.

Infinite Scrolling: Automatically load more movies as the user scrolls down.

Client-Side Routing: Navigate between pages using React Router.

API Integration: Fetch movie data using Axios.

🛠️ Technologies Used

React

JavaScript (ES6+)

React Router

Axios

TMDB API

Lodash (Debounce)

Intersection Observer API
